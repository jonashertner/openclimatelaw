OpenAI Agents SDK (Python)

from agents import Agent, Runner
from agents.mcp import MCPServerStreamableHttp

async with MCPServerStreamableHttp(
    name="openclimatelaw",
    params={"url": "https://mcp.openclimatelaw.org/mcp"},
) as server:
    agent = Agent(name="research", mcp_servers=[server])
    result = await Runner.run(agent, "Find Urgenda v. Netherlands and cite it.")
    print(result.final_output)

Google AI Studio / Vertex AI via tools API

Gemini's tool-use API can call MCP servers via the SDK's MCP client integration:

import asyncio
from google import genai
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

async def run():
    async with streamablehttp_client("https://mcp.openclimatelaw.org/mcp") as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            client = genai.Client()
            resp = await client.aio.models.generate_content(
                model="gemini-2.5-pro",
                contents="How many climate cases involve Germany? Use the MCP tools.",
                config={"tools": [session]},
            )
            print(resp.text)

asyncio.run(run())

Other MCP clients

Any MCP client supporting Streamable HTTP works. Point it at https://mcp.openclimatelaw.org/mcp.

  • Cursor: Settings → MCP → Add new MCP server → URL transport.
  • Continue.dev: add to ~/.continue/config.yaml under mcpServers with type: streamable-http.
  • Cline (VS Code): MCP Servers panel → Edit settings → add a URL entry.
  • Goose: goose configure → Add MCP Server → choose SSE or HTTP.
  • Zed: add to settings.json under "context_servers".
  • Custom code: any HTTP client speaking the MCP Streamable HTTP spec.

What you can do

Six tools available right now:

  • search_cases(query, jurisdiction?, claim_type?, status?, limit?) — free-text search over titles + summaries with optional filters. Returns ranked matches with sabin_id, title, summary excerpt, and a verbatim citation_string — the right entry point when you don't already have a case_id.
  • get_case(case_id_or_sabin_id) — full case record: parties, claim types, documents (with extracted text where available), citation strings, field-level provenance.
  • get_statistics(scope, group_by?) — aggregates: case/doc/statute counts, group by jurisdiction / claim_type / year / status / outcome.
  • cite(case_id, lang, format) — verbatim citation_string for a case in a given language and format. R1: never construct citations from training data.
  • check_claim_support(quote, source_id, source_kind) — verify a quotation appears verbatim in case_summary / document_text / citation_string. R2. Note: document_text requires a document UUID (from get_case().documents[].id), not a case ID.
  • attest_response(draft_text, retrieved_ids[]) — scans a draft for citation-shaped strings (ECLI, BVerfGE, BGE, US reporter) and flags any not present in the citation_strings of the retrieved cases. R1 enforcement.

Coming next: find_citations / find_cited_by, statute layer (CCLW), and a unified find_related_cases.

Anti-hallucination contract

The MCP enforces three rules from the project spec:

  • R1 (don't fabricate citations): every case reference returned includes a verbatim citation_string. Use cite() to fetch one — never construct from training data. attest_response() catches violations after the fact.
  • R2 (don't misquote): use check_claim_support() to verify any quotation appears verbatim in the named source.
  • R5 (don't fudge outcomes): get_case returns structured status_code from the source taxonomy.

Try it

Once connected, ask in any compatible client:

  • "Search the climate-litigation corpus for 'Amazon deforestation' filed in Brazil and tell me the top 5 cases."
  • "Find Urgenda v. Netherlands, cite it in en/sabin format, and quote one sentence from its summary verbatim — but verify the quote first."
  • "Find youth-plaintiff cases in the US and summarize their claim types."
  • "How many climate cases are there per jurisdiction? Show the top 10."
  • "Validate this draft: 'In ECLI:NL:HR:2019:2007 the court reasoned, citing Massachusetts v. EPA, 549 U.S. 497 (2007)...' against retrieved cases [urgenda-foundation-v-state-of-the-netherlands]."

Data sources & licence

Centred on the Sabin Center for Climate Change Law's Climate Litigation Database (~4,830 cases, full metadata + summaries + court-document text), scraped directly from www.climatecasechart.com under the CC-BY 4.0 licence Sabin publishes the data under. PDFs are downloaded only from climatecasechart.com/wp-content/uploads/... (Sabin's own domain). No third-party API in the loop.

Metadata-only references to Climate Rights Database cases are also included with redirect-to-source links (215 cases, no full text — consult CRD directly for substantive content).

Per CC-BY 4.0, every citation_string returned by this MCP carries upstream attribution. The MCP server itself is open-source under the MIT licence.
